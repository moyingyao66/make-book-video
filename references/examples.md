# Filled output examples

These examples demonstrate stable output shape. They are illustrative only: they do not prove a provider call, user approval, editor readback, media QA, or a trigger-rate baseline.

## Example 1: startup choice result

Input: `把《思考，快与慢》做成竖屏卖书视频，后面我还要自己换图。`

Host choice result:

```json
{
  "opening_media": "pexels-video",
  "body_media": "gpt-image"
}
```

Persisted case fragment:

```json
{
  "visualSourcePolicy": {
    "selectionStatus": "confirmed",
    "selectionMethod": "host-structured-choice",
    "selectedAtProjectStart": true,
    "openingSource": "pexels-video",
    "bodySource": "gpt-image",
    "silentFallbackAllowed": false
  }
}
```

The labels shown by the host may differ, but the stored option IDs and method do not.

## Example 2: approval package for preserved copy

Input: an already approved short script that must keep its wording and order. This compact example uses `preserve-approved-script`; the default profile's normal length contract does not apply.

```markdown
# 《思考，快与慢》生成前确认包

## 请确认

- [ ] 完整旁白内容
- [ ] 语义分镜与素材方向
- [ ] 确认后授权完整 TTS 与批量素材生成

## 项目摘要

- 书名：《思考，快与慢》
- 作者：丹尼尔·卡尼曼
- 目标观众：重大决定容易被第一印象带走的人
- 单一主论点：答案来得越快，越要检查原问题
- 开场素材：pexels-video
- 正文素材：gpt-image

## 完整旁白

今天分享的是。丹尼尔·卡尼曼的《思考，快与慢》。当一个答案立刻跳出来时，先问自己：我回答的，还是原来那个问题吗？

## 证据边界

- 主研究路径：weread-skills
- 微信读书 bookId：已记录于 case.json
- 私人笔记：未使用

| Claim | 类别 | 表述边界 | 来源 |
|---|---|---|---|
| claim-question-substitution | attributed | 书中讨论用较容易的问题替换较难的问题 | 实际来源保留在 case.json |
| claim-pause | interpretation | “先问自己”是创作者实践建议，不冒充作者原话 | research.md |

## 语义分镜

| 顺序 | 场景职责 | 旁白 | 画面意图 | 素材 | 证据 |
|---:|---|---|---|---|---|
| 1 | fixed-opening | 今天分享的是。 | 已选开场素材 | assets/pexels/intro.mp4 | — |
| 2 | book-reveal | 丹尼尔·卡尼曼的《思考，快与慢》。 | 真实主封面 | visuals/book-reveal.png | — |
| 3 | body | 当一个答案立刻跳出来时…… | 可识别的重大决定场景 | visuals/body.png | claim-question-substitution, claim-pause |
```

The real package is generated by `build_approval_package.py`; never copy this example into a project or hand-edit approval state.
